# **过滤器接口设计**
## 通过tableName获取表字段列表

**接口地址** `/{service-name}/{model-name}/table-filter/access`

**请求方式** `GET`

**接口描述** ``

##### **请求参数**

| 参数名称         | 参数说明     |     请求类型 |  是否必须      |  数据类型   |  


**响应状态**

| 状态码         | 说明                             |    schema                         |
| ------------ | -------------------------------- |---------------------- |
| 200         | OK                        |Result«List«TableFilterDto«TableSelectFilterDto»»»                          |
| 401         | Unauthorized                        |                          |
| 403         | Forbidden                        |                          |
| 404         | Not Found                        |                          |




**响应参数**

| 参数名称         | 参数说明                             |    类型 |  schema |
| ------------ | -------------------|-------|----------- |
| code     |错误码      |    string   |       |
| data     |响应数据      |    array   |   TableFilterDto«TableSelectFilterDto»    |
| msg     |响应消息      |    string   |       |
| succ     |响应状态      |    boolean   |       |
| timestamp     |时间戳      |    integer(int64)   |   integer(int64)    |




**schema属性说明**

**TableFilterDto«TableSelectFilterDto»**

| 参数名称         | 参数说明                             |    类型 |  schema |
| ------------ | ------------------|--------|----------- |
| data         |     多选框、下拉树多选的时候，返回数组      |  array   | TableSelectFilterDto     |
| dateFormat         |     日期是否需要转换【当type属于DatePicker、RangePicker的时候，需要传这个值】，用于把日期字符串转为数据库date格式      |  boolean   |      |
| defaultValue         |     默认值      |  string   |      |
| format         |     日期格式：只有DatePicker、RangePicker需要返回这个格式，其他格式固定。时间段的时候，format只有一个值，无需逗号分隔      |  string   |      |
| key         |     表单标签关键字，参数名      |  string   |      |
| name | 表单标签名称，用于前端显示【如果是时间段，逗号分隔】 |  | |
| operationType         |     操作类型,可用值:eq,ne,gt,ge,lt,le,between,notBetween,like,notLike,likeLeft,likeRight,in,notIn      |  string   |      |
| type         |     表单类型：Input[输入框]、Select[下拉框]、MultSelect[下拉多选框]、TreeSelect[下拉树]、Checkbox[复选框]、DatePicker【时间框】、MonthPicker【年月选择框】、RangePicker【时间段选择框】、TimePicker[时分秒选择框],可用值:Input,Select,MultSelect,TreeSelect,MultTreeSelect,Checkbox,DatePicker,MonthPicker,RangePicker,TimePicker      |  string   |      |


**TableSelectFilterDto**

| 参数名称         | 参数说明                             |    类型 |  schema |
| ------------ | ------------------|--------|----------- |
| text         |     select标签显示的文本      |  string   |      |
| value         |     select标签隐藏显示的值，用于传参用      |  string   |      |


**针对不同类型表单类型，返回示例：**

1. Input[输入框]


```json
{
  "code": "200",
  "data": [
    {
      "name":"名称",
      "key": "name",               表单标签关键字，参数名【查询传给接口】
      "operationType": "like",	   查询操作类型【查询传给接口】	
      "type": "Input"			  表单类型【查询传给接口】
    }
  ],
  "msg": "获取Users表格过滤器信息",
  "succ": true,
  "timestamp": 1595213249522
}
```

​		查询表格入参示例：

```json
{

		}
	]
}
```
